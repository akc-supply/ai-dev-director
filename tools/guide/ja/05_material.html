完成品がどの資材を何個ずつ使って作られるか（BOM）、資材をいくらで買っているか（仕入単価）を調べて修正する場所です。

資材を探す · 修正する

操作手順 · BOM（資材明細書）
  1. BOM（資材明細書） タブを押します。

    初回はデータを受信するため進行バーが回ります。次回からはすぐに表示されます。

  2. 検索欄に品番 · 品名 · 工程名などを入れます。

    区分 · Level · 顧客 でさらに絞り込みます。すべて解除するには リセット。50件ずつページに分かれます。

  3. 行を押すと BOM 詳細仕様 ウィンドウが開きます。

    上位 · 下位の情報、工程 · 生産の仕様、備考。顧客名を押すと取引先の情報が表示されます。

  4. 修正するには 修正 → 値を変更 → 保存する。
  5. 必要なら Excel で、いま絞り込んだ一覧をダウンロードします。

    ファイル名：BOM자재명세서_날짜.xlsx（BOM資材明細書_日付）

  • 下位単位（UM）を修正すると、その品番について別に記憶するので、BOM を再アップロードしても維持されます。表ではオレンジ色の文字で表示されます。欄を空にすると元の単位に戻ります。
  • Level 1 は緑、2 は青のタグです。所要量 = 上位品目1つに必要な個数。
詳細ウィンドウの削除は、その行をデータベースから完全に消します。削除する前に、上位 · 下位の品番をもう一度確認してください。

仕入単価 · 製品材料費

  • 仕入単価明細書：検索欄（品目コード · 品目名 · 業者名 · 規格）+ 業者 · 通貨 · 区分のセレクター → 結果の中で 略語 · 品目種類 でもう一度絞り込みます。詳細 → 単価情報 → 修正 → 保存する。Excel は絞り込んだ一覧のまま。
  • M-BOM（製品材料費）：大分類（プロジェクト）を展開して製品を選ぶと、1個作る総材料費が表示されます。単位が違う単価は 単価数式を適用（× 10、÷ 100 など）で合わせ、再アップロードしても維持されます。解除するには 数式解除。

BOM · 単価ファイルのアップロード

操作手順 · BOM のアップロード
  1. BOM 管理の右上 設定 → データアップロードへ移動します。

    メイン画面の設定 › アップロードではなく、BOM 管理の中の設定 です。

  2. BOM は BOM アップロード に Frm_MASTER BOM ファイルを1つアップロードします。
  3. 単価は 完成品ファイル選択 · 半製品ファイル選択 → 単価アップロード（完成品+半製品を結合）。

    様式は 様式ダウンロード。アップロードした種類だけが新しくなり、手で変更した下位単位は維持されます。

資材管理 · はじめに

サイドバー › 業務 › 資材管理権限：資材管理（メール設定 · データ点検：マスター）

毎日の使い方

操作手順 · 資材管理の1日の流れ
  1. （データ担当）MES のデータをアップロードします。

    設定 › アップロード › 資材管理4種（仕入 · 外注賃加工 · 商品売上 · 海外出庫）。→ アップロード › 資材管理 MES

  2. 右上の 再計算 を押します。

    アップロード後に一度押すと、最新のデータで計算し直します。資料行 の日付が最近のものか確認してください。

  3. ダッシュボード › 在庫・枯渇 のカードを見ます。

    即時調達 · 今週発注 · 4週以内に発注の件数を確認します。→ ダッシュボード

  4. 資材管理 の一覧で、急ぎの資材を開きます。

    在庫切れ予想 · 発注時点を見て、必要なら入庫予定を登録したり入庫を確認したりします。→ 資材一覧 · 詳細

  5. 発注計画管理 で月の発注計画を入力し、協力会社に送ります。

    → 発注計画管理

  6. （生管）無償出庫依頼 の確認待ち · 遅延の依頼を処理します。

    サンプル · 搬出の依頼を確認し、出庫完了まで処理します。→ 無償出庫依頼

照会条件を選ぶ

  • 基準日：今日（初期値）または受払台帳の締め日（例：8/31 締め）。資材管理の計算にも使われます。
  • 資材区分：すべて / 海外（輸入）/ 国内。品目群：全資材 · 主要資材 · ★ 重点管理 · ★ インフレーター · ★ OPW · ★ ワイヤーハーネス · VINFAST · KGM 共用 · 海外リードタイム 90 · 60 · 45日以上。
  • JG除外 · 商品除外 は最初からチェックされています。
  • 区分 · 顧客 · 仕入先は、すべての画面で同じ値を使います。1か所で変えると、ほかの画面も変わります。
  • 初期値以外の絞り込み欄は 緑 に変わり、↺ リセット が表示されます。

急ぎの資材を探す

操作手順 · 一覧で絞り込む
  1. 状態バーで 欠品 · 緊急 の欄を押します。

    その状態だけが残ります。もう一度押すと、すべてに戻ります。

  2. 発注時点 で 発注時点を経過 · 7日以内に発注 を選びます。

    発注済みのものだけを見るには 📦 入庫待ち（発注済み）。

  3. 検索欄に品番 · 品名 · 親品番 · 仕入先を入れます。

    品番は - やスペースなしで入れても見つかります（例：569036AA26 = 569036-AA26）。表示されない場合は、理由（例：品目群に入っていない）と この資材を開く → が表示されます。

  4. 行を押すと、資材詳細が全画面で開きます。

    ← 一覧へ · Esc · ブラウザの戻るで戻ると、絞り込みとスクロール位置はそのままです。

  • 表の色のまとまり：青灰 = 現在の在庫（保有 · 在庫切れ予想）、薄緑 = 1次入庫予定、薄紫 = 2次入庫予定。入庫を加えても在庫切れ日が同じなら 変化なし（入庫が在庫切れより遅い）。
  • 親品番欄の +N を押すと、その場ですべて展開されます。コピー は改行区切りで全部コピーし、文字をドラッグして一部だけコピーしても詳細には移動しません。
  • 入庫欄の + 入力 や日付を押すと、詳細に入らずに小さなウィンドウで入庫予定の登録 · 修正 · 入庫確認ができます。
  • 休眠資材は、下の ▸ 💤 休眠資材 N 件 … 展開 の中に折りたたまれています。判定が違う場合は詳細で変更します → 休眠在庫 · 在庫切れ後は使用しない
  • 1次 · 2次の入庫日の横の小さな表示：🚚 発送確認 · 🗓 出発予定 · ⚠ 出発予定超過 → 協力会社の発送記録

リードタイムを直す

操作手順 · リードタイムを直す
  1. 詳細の リードタイム カードで ✎ 修正 を押します。

    カードに今の値の出どころ（品目基準表 · 既定値 · ✎ 直接修正）が表示されます。

  2. 日数（1 ～ 365）を入れます。

    入力中に、変わる発注必要日がプレビューされます。

  3. 保存（または Enter）を押します。

    発注必要日 · 状態 · ダッシュボード · メールが新しい値で再計算され、一覧 · ダッシュボード · 発注計画管理に ✎ 印が付きます。元に戻すには ↺ … に戻す。

休眠在庫 · 在庫切れ後は使用しない の切り替え

詳細ヘッダー右側の2つのスイッチで、資材を通知 · 発注から外したり戻したりします。切り替えると、画面 · 自動メール · AI 検索が同じ判定で再計算します。

スイッチオンにするとこんなとき
💤 休眠在庫休眠とみなす — 発注通知 · メール · 一覧の標準表示から外れ、一覧下の 💤 グループに入ります。オフにすると休眠ではない在庫（欠品 · 発注通知の対象）生産が終わった、または当面使わない資材 · 逆に使っているのに休眠と誤判定された資材
在庫切れ後は使用しない（再発注しない）残りの在庫だけを使い、再発注しない — 欠品 · 緊急 · 発注必要の通知、メールの発注表、発注計画の自動入力から外れ、在庫切れ予想日だけを表示廃番予定 · 別の品番に切り替わる資材（ジニョン電機のワイヤーハーネス15件は最初からオン）
操作手順 · 休眠在庫を直接指定する
  1. 資材の詳細を開き、ヘッダー右側の 💤 休眠在庫 スイッチを見ます。

    スイッチ末尾の 自動 = システムが判定した値、手動 = 誰かが指定した値です。マウスを乗せると、自動判定とその理由（例：直近30日の使用0 · 今後60日の需要0）、指定した人 · 日付が表示されます。

  2. スイッチをオン / オフにします。

    待機行をすぐ出すときは詳細ウィンドウの 📦 すぐ出庫完了、複数行はチェック後に上の帯の 📦 出庫完了。

  2. 出庫日（今日まで）· 出庫場所（倉庫 · ライン）を入れます。
  3. 行ごとに 出庫数量 と 在庫から差し引く を確認します。

    オンのままにすると、出庫日に出庫数量分が資材管理の入庫 · 在庫記録にマイナスで入り、在庫 · 在庫切れ予想がすぐ変わります。数量が「1 BOX」のような文字なら記録だけ残り、在庫からは差し引きません（数字で入れると差し引く）。

  4. 📦 出庫完了 を押します。

    状態が 出庫完了 になり、表の 出庫 欄に 在庫 −N が表示されます。

  • 差戻し：差戻し → 差戻し理由（必須）→ 差戻し。再び受けるには詳細ウィンドウの 差戻し解除。
  • 取り消し（詳細ウィンドウ）：確認取消 = 待機へ（自動登録した入庫予定は削除 · すでに入庫確認済みのものはそのまま）· 出庫完了取消 = 処理中へ（在庫から差し引いた記録を消して在庫を戻す）。
詳細ウィンドウの 削除 は、つながっている資材管理の入庫予定 · 在庫記録まで一緒に消し、元に戻せません。

依頼書 Excel のアップロード（マスター）

操作手順 · 「サンプル & 搬出依頼書」のアップロード
  1. 📤 Excel アップロード を押し、ファイルをドラッグします。

    複数のファイルを一度に選んでも大丈夫です。ファイル名の月（例：2026 10월 무상출고.xlsx → 10月）を依頼書の月として使います。

  2. ファイルごとにプレビューを確認します。

    新規 · 変更 · 同じの件数と警告（日付を読めなかった欄など）が出ます。▸ 行を見る で行を展開します。

  3. 保存 を押します。

    再度アップロードすると、同じ行（月 · No · 品番）は更新し、新しい行だけ追加します。画面で生管が処理した値は上書きしません。出庫完了の行は 出庫完了の行は資材管理の在庫から差し引く で在庫にも反映できます。

同じファイルの「品目情報」シートも保存され、+ 新規依頼 ウィンドウで品番だけ入れると、Excel の VLOOKUP と同じ品名 · 単位が入ります。

操作手順 · 自動メールの設定
  1. 最上部の 自動送信 スイッチをオンにします。
  2. ① で、グループごとに予約スイッチ · 時刻 · 毎日 または 曜日選択 を決めます。

    ◉ はプレビュー · テスト · 今すぐ送信の対象グループです。同じグループは1日1回だけ送られ、送るものがなければ スキップ と記録されます。

  3. ② で、入れる表を選びます。

    即時調達 · 今週発注 · 4週以内に発注。海外 + 国内の選択は すべて グループにだけ使われます。

  4. ③ で宛先を展開して確認します。

    3つのグループは同じ人に送られます。名前 · ID · アドレスの一部で探して Enter、⇄ またはドラッグで宛先 ↔ CC、× で外します。

  5. プレビュー → 自分にテストメール で確認し、保存。

    すぐ送るには 今すぐ送信（◉ グループ · そのグループの今日の自動送信はスキップ）。

資料基準 に ⚠ が表示されたら、生産実績 · MES 入庫が3日以上アップロードされていない、MES 生産計画が7日以内に終わる、または計算の基準日が今日と違う、のいずれかです。メールの数字が実際と違う可能性があるので、まずデータをアップロードしてください。
  • メールの表は、入庫予定がある資材を下の 📦 発注済み · 入庫確認 グループとして別に表示します（件数はダッシュボードのカードと同じ）。
  • メールの発注済みの行には、協力会社の発送（🚚 発送 · 出発予定 · ⚠ 出発予定超過）も表示されます。→ 協力会社の発送記録
  • スマホ通知 · 音声案内：AKC の Android アプリが即時調達の内容を読み上げます。初期値は 08:30 · 17:30、週末も。保存 · 試聴 · 自分の携帯でテスト。資材管理の権限がある人の登録端末に送られます。
  • 送信履歴：直近20件（時刻 · 種類 · 結果 送信/スキップ/失敗 · 内容）。

計算に使うデータが互いに正しくつながっているかを点数で表示します（80%以上は緑 · 50%以上は黄 · それ未満は赤）。資料別のカード、8月に差が大きい資材、単位が異なる資材、BOMがない計画品番、品番検索（どの品番がなぜ表示されないか）、漏れリスク点検 7項目を見ます。数字がおかしいときは、まずここを確認してください。
