BOM 관리

사이드바 › 업무 › BOM 관리권한: BOM 관리

완제품이 어떤 자재로 몇 개씩 만들어지는지(BOM), 자재를 얼마에 사는지(매입단가)를 찾아보고 고치는 곳입니다.

위 탭하는 일
BOM (자재명세서)상위 · 하위 품목, 소요량, 공정, M/C, 고객사를 한 줄씩 봅니다.
매입단가 명세서품목별 매입단가(MAX · MIN · AVG)와 변동을 봅니다.
M-BOM제품재료비 현황 — 제품 하나 만드는 데 드는 총 재료비(유상사급 제외)
E-BOM · F-BOM엔지니어링 · 재무 BOM 을 직접 적어 관리 (F-BOM 은 금액 · 통화 · 환율 포함)

자재 찾기 · 고치기

따라하기 · BOM (자재명세서)
  1. BOM (자재명세서) 탭을 누릅니다.

    처음 한 번은 자료를 받느라 진행 막대가 돕니다. 다음부터는 바로 뜹니다.

  2. 검색 칸에 품번 · 품명 · 공정명 등을 넣습니다.

    구분 · Level · 고객사 로 더 좁힙니다. 다 풀려면 초기화. 50건씩 쪽으로 나뉩니다.

  3. 줄을 누르면 BOM 상세 제원 창이 열립니다.

    상위 · 하위 정보, 공정 · 생산 제원, 비고. 고객사명을 누르면 거래처 정보가 보입니다.

  4. 고치려면 수정 → 값 변경 → 저장하기.
  5. 필요하면 엑셀 로 지금 걸러 놓은 목록을 받습니다.

    파일 이름 : BOM자재명세서_날짜.xlsx

  • 하위 단위(UM)를 고치면 그 품번에 대해 따로 기억해서 BOM 을 다시 올려도 유지됩니다. 표에서 주황빛 글자로 보입니다. 칸을 비우면 원래 단위로 돌아갑니다.
  • Level 1 은 초록, 2 는 파랑 꼬리표입니다. 소요량 = 윗 품목 하나에 드는 개수.
상세 창의 삭제는 그 줄을 데이터베이스에서 아주 지웁니다. 지우기 전에 상위 · 하위 품번을 한 번 더 확인하세요.

매입단가 · 제품재료비

  • 매입단가 명세서 : 검색 칸(품목코드 · 품목명 · 업체명 · 규격) + 업체 · 통화 · 구분 고르개 → 결과 안에서 약어 · 품목 종류 로 한 번 더 좁힙니다. 상세보기 → 단가 정보 → 수정 → 저장하기. 엑셀 은 좁힌 목록 그대로.
  • M-BOM (제품재료비) : 대분류(프로젝트)를 펼쳐 제품을 고르면 1개 만드는 총 재료비가 나옵니다. 단위가 다른 단가는 단가 수식 적용(× 10, ÷ 100 등)으로 맞추고, 다시 올려도 유지됩니다. 풀려면 수식 해제.

BOM · 단가 파일 올리기

따라하기 · BOM 올리기
  1. BOM 관리 오른쪽 위 설정 → 데이터 업로드로 갑니다.

    본 화면 설정 › 업로드가 아니라 BOM 관리 안의 설정입니다.

  2. BOM 은 BOM 업로드 에 Frm_MASTER BOM 파일 1개를 올립니다.
  3. 단가는 완제품 파일 선택 · 반제품 파일 선택 → 단가 업로드 (완제품+반제품 병합).

    양식은 양식다운. 올린 종류만 새것으로 바뀌고, 직접 바꿔 둔 하위 단위는 지켜집니다.

자재관리 · 시작하기

사이드바 › 업무 › 자재관리권한: 자재관리 (이메일 설정 · 데이터 점검 : 마스터)

8/31 수불부 재고에 MES 입고 · 생산실적을 반영하고, BOM × 생산계획 · 롤링 S/L 로 앞으로 쓸 양을 셈해서 어떤 자재가 언제 떨어지고 언제 발주해야 하는지 알려 줍니다.

화면 구성 · 위에서 아래로
  1. 위 메뉴대시보드 · 자재관리 · 발주계획관리 · 무상출고요청 · 생산 차질 점검 · 수불부 기준 · 이메일 설정 · 데이터 점검 · 오른쪽 새로 계산
  2. 제목 줄화면 이름 · 내보내기(CSV)
  3. 조회 조건기준일 · 자재 구분 · 품목군 · 고객사 · 매입처 · JG 제외 · 상품 제외 (대시보드 재고 · 소진, 생산 차질 점검, 수불부 기준)
  4. 자료 줄수불부 · BOM · 생산계획 · VF 롤링 S/L · 생산실적 · MES 입고 · 수입자재 목록 칩 (초록 = 있음, 빨강 = 없음)과 자료 날짜

위 메뉴의 숫자 : 대시보드 = 결품 + 긴급 자재 수, 자재관리 = 집중 관리(인플레이터 · OPW · 와이어하네스) 중 조치가 필요한 수, 무상출고요청 = 확인 기다림 · 지연 요청 수, 생산 차질 점검 = 생산불가 완성품 수.

매일 쓰는 순서

따라하기 · 자재관리 하루 흐름
  1. (자료 담당) MES 자료를 올립니다.

    설정 › 업로드 › 자재관리 4종(매입 · 외주임가공 · 상품매출 · 해외출고). → 업로드 › 자재관리 MES

  2. 위 오른쪽 새로 계산 을 누릅니다.

    업로드 뒤 한 번 누르면 최신 자료로 다시 셉니다. 자료 줄의 날짜가 최근인지 확인하세요.

  3. 대시보드 › 재고 · 소진 카드를 봅니다.

    즉시 조달 · 이번 주 발주 · 4주 안 발주 건수를 확인합니다. → 대시보드

  4. 자재관리 목록에서 급한 자재를 엽니다.

    소진 예상 · 발주 시점을 보고 필요하면 입고 예정을 등록하거나 입고를 확인합니다. → 자재 목록 · 상세

  5. 발주계획관리 에서 월 발주계획을 적고 협력사에 보냅니다.

    → 발주계획관리

  6. (생관팀) 무상출고요청 의 확인 기다림 · 지연 요청을 처리합니다.

    샘플 · 반출 요청을 확인하고 출고 완료까지 처리합니다. → 무상출고요청

조회 조건 고르기

  • 기준일 : 오늘(기본) 또는 수불부 마감일(예: 8/31 마감). 자재관리 계산에도 같이 쓰입니다.
  • 자재 구분 : 전체 / 해외 (수입) / 국내. 품목군 : 전체 자재 · 주요자재 · ★ 집중 관리 · ★ 인플레이터 · ★ OPW · ★ 와이어하네스 · VINFAST · KGM 공용 · 해외 리드타임 90 · 60 · 45일 이상.
  • JG 제외 · 상품 제외 는 처음부터 체크되어 있습니다.
  • 구분 · 고객사 · 매입처는 모든 화면이 같은 값을 씁니다. 한 곳에서 바꾸면 다른 화면도 바뀝니다.
  • 기본값이 아닌 거르기 칸은 초록으로 바뀌고 ↺ 초기화 가 나타납니다.

자재 대시보드

자재관리 › 대시보드

위 탭으로 네 가지를 봅니다 : 생산 · 출고 · 협력사 매입 · 외주 · 재고 · 소진 · 발주계획. 처음엔 이번 달 기준입니다.

재고 · 소진 — 무엇이 언제 떨어지나

따라하기 · 급한 자재 찾기
  1. 재고 · 소진 탭을 누르고 위 카드 4장을 봅니다.

    즉시 조달(결품) · 이번 주 발주(발주 권장일 7일 안 · 지난 것 포함) · 4주 안 발주(8~28일) · 휴면 · 재고 없음. 카드 아래에 📦 발주 완료 N 이 함께 보입니다.

  2. 카드를 누르면 목록 창이 뜹니다.

    창 안의 아래 표를 이 조건으로 거르기 를 누르면 아래 표가 그 조건으로 좁혀집니다.

  3. 앞으로 12주 · 주별 소진 예정 자재 막대를 봅니다.

    파랑 = 해외, 회색 = 국내, ★ = 집중 관리. 막대를 누르면 그 주만, 주 선택 풀기 ✕ 로 풉니다.

  4. 표 위 상태 막대나 거르기로 좁힙니다.

    상태 막대 칸을 누르면 그 상태만, 다시 누르면 전체. 검색 · 상태 · 사용량 근거 · 사용 중인 것만.

  5. 줄을 누르면 옆 창에 자세한 내용이 나옵니다.

    기준재고 · 추정 재고 · 입고 · 일 사용 · 120일 예상 재고 선 · 이 자재를 쓰는 완성품.

발주 권장 칸뜻
📦 발주 완료 + 입고 MM/DD입고 예정이 잡혀 있음 = 이미 발주함. 예정일에 들어왔는지 확인
⚠ 입고 지연 확인입고 예정일이 지남
🚚 MM/DD 발송 · 🗓 MM/DD 출발 예정 · ⚠ 출발 MM/DD 지남협력사 발송 기록 — 물건이 출발했는지 · 출발 예정일이 지났는지 → 협력사 발송 기록
추가 발주 MM/DD예정이 다 들어와도 그 뒤 다시 발주해야 함
즉시 조달 · N일 지남 · 오늘 · MM/DD · D-N아직 발주하지 않은 자재의 발주 시점

생산 · 출고 · 협력사 매입 · 발주계획

  • 생산 · 출고 : 자료 생산실적 / 상품매출 / 해외출고. 조회 년 → 조회 월(년을 먼저 골라야 함) · 세부 · 구분 · 고객사 · 검색. 카드(생산 수량 · 하루 평균 · 품번 · 불량률), 날짜별 · 상위 10 그래프, 품번 표. 줄을 누르면 날짜별 그래프와 BOM 자재가 나옵니다.
  • 협력사 매입 · 외주 : 자료 매입 / 외주임가공. 카드(매입 금액 · 협력사 · 입고 수량 · 확인 대기 · 반품), 월별 · 상위 10 협력사, 협력사별 표(확정 초록 · 대기 노랑 · 반품 빨강). 줄을 누르면 품번별 · 입고 내역.
  • 발주계획 : 기간 시작 ~ 기간 끝 · 빠른 기간(FIRM / FORECAST / 10개월 / 지난 6개월) · 업체 · 품목. 월별 막대(초록 FIRM · 보라 FORECAST · 회색 PAST)와 예상 사용량 선. 협력사 · 자재 줄을 누르면 발주계획관리에서 그 협력사 · 품번이 열립니다.

표 머리를 누르면 정렬되고, 쪽당 줄 수는 50 / 100 / 200 에서 고릅니다.

급한 자재 찾기

따라하기 · 목록에서 좁히기
  1. 상태 막대에서 결품 · 긴급 칸을 누릅니다.

    그 상태만 남습니다. 다시 누르면 전체로 돌아갑니다.

  2. 발주 시점 에서 발주 시점 지남 · 7일 안 발주 를 고릅니다.

    이미 발주한 것만 보려면 📦 입고 대기 (발주 완료).

  3. 검색 칸에 품번 · 품명 · 모품번 · 매입처를 넣습니다.

    품번은 - · 띄어쓰기 없이 넣어도 찾습니다(예: 569036AA26 = 569036-AA26). 안 나오면 까닭(예: 품목군에 들지 않음)과 이 자재 바로 열기 → 가 나옵니다.

  4. 줄을 누르면 자재 상세가 전체 화면으로 열립니다.

    ← 목록으로 · Esc · 브라우저 뒤로 가기로 돌아오면 거르기와 스크롤 위치가 그대로입니다.

  • 표의 색 묶음 : 회청 = 현재 재고(보유 · 소진 예상), 연초록 = 1차 입고 예정, 연보라 = 2차 입고 예정. 입고를 더해도 소진일이 같으면 변화 없음(입고가 소진보다 늦음).
  • 모품번 칸의 +N 을 누르면 그 자리에서 모두 펼쳐집니다. 복사 는 줄바꿈으로 전부 복사, 글자를 끌어 일부만 복사해도 상세로 넘어가지 않습니다.
  • 입고 칸의 + 입력 이나 날짜를 누르면 작은 창에서 상세로 들어가지 않고 입고 예정 등록 · 수정 · 입고 확인을 합니다.
  • 휴면 자재는 아래 ▸ 💤 휴면 자재 N개 … 펼치기 안에 접혀 있습니다. 판정이 틀리면 상세에서 바꿉니다 → 휴면 재고 · 소진 후 사용 안 함

리드타임 고치기

따라하기 · 리드타임 고치기
  1. 상세의 리드타임 카드에서 ✎ 수정 을 누릅니다.

    카드에 지금 값이 어디서 왔는지(품목 기준표 · 기본값 · ✎ 직접 수정) 보입니다.

  2. 일수(1 ~ 365)를 넣습니다.

    넣는 동안 바뀔 발주 필요일이 미리 보입니다.

  3. 저장(또는 Enter)을 누릅니다.

    발주 필요일 · 상태 · 대시보드 · 메일이 새 값으로 다시 셈해지고, 목록 · 대시보드 · 발주계획관리에 ✎ 표시가 붙습니다. 원래대로 돌리려면 ↺ … 로 되돌리기.

휴면 재고 · 소진 후 사용 안 함 바꾸기

상세 머리 오른쪽 스위치 두 개로 자재를 알림 · 발주에서 빼거나 다시 넣습니다. 바꾸면 화면 · 자동 메일 · AI 검색이 같은 판정으로 다시 셉니다.

스위치켜면이럴 때
💤 휴면 재고휴면으로 봄 — 발주 알림 · 메일 · 목록 기본 보기에서 빠지고 목록 아래 💤 묶음으로 갑니다. 끄면 휴면이 아닌 재고(결품 · 발주 알림 대상)생산이 끝났거나 당분간 안 쓰는 자재 · 반대로 쓰는데 휴면으로 잘못 나온 자재
소진 후 사용 안 함 (재주문 안 함)남은 재고만 쓰고 재주문하지 않음 — 결품 · 긴급 · 발주 필요 알림, 메일 발주 표, 발주계획 자동 채우기에서 빠지고 소진 예상일만 보임단종 예정 · 다른 품번으로 바뀌는 자재 (진영전기 와이어하네스 15개는 처음부터 켜짐)
따라하기 · 휴면 재고 직접 정하기
  1. 자재 상세를 열고 머리 오른쪽 💤 휴면 재고 스위치를 봅니다.

    스위치 끝의 자동 = 시스템이 판정한 값, 직접 = 누군가 정한 값입니다. 마우스를 올리면 자동 판정과 까닭(예: 최근 30일 사용 0 · 앞으로 60일 수요 0), 정한 사람 · 날짜가 보입니다.

  2. 스위치를 켜거나 끕니다.

    켜면 휴면 재고로 표시했습니다, 끄면 휴면 재고가 아닌 재고로 되돌렸습니다 가 뜹니다. 직접 휴면으로 정한 자재는 대시보드 표에 💤 휴면 (직접 지정) 으로 보입니다.

  3. 자동 판정으로 돌리려면 스위치를 자동 판정과 같은 쪽으로 다시 돌립니다.

    직접 지정이 지워지고 스위치 끝이 자동 으로 돌아갑니다.

따라하기 · 소진 후 사용 안 함
  1. 상세 머리 오른쪽 소진 후 사용 안 함 (재주문 안 함) 스위치를 켭니다.

    소진 후 단종으로 표시했습니다 가 뜨고 상태가 소진 후 단종, 목록의 발주 칸이 재주문 안 함 이 됩니다.

  2. 다시 발주 대상으로 돌리려면 스위치를 끕니다.

    소진 후 단종 표시를 껐습니다 — 다시 발주 알림 대상입니다 가 뜹니다.

입고 예정 · 입고 확인 · 보유수량 맞추기

상세 아래 자세히 보기 의 📦 입고 · 재고 기록 카드를 누릅니다. 새 기록을 넣는 칸이 위, 기록 목록이 아래에 있습니다.

따라하기 · 입고 예정 등록 (발주했을 때)
  1. 종류 단추에서 📦 입고 예정 을 고릅니다.
  2. 입고 예정일 · 수량 을 넣고, 메모 (선택) 에 PO 번호 · 선적일 등을 적습니다.
  3. 아래 미리 보기 줄을 확인합니다.

    등록하면 → 소진 예상 A → B (+N일) · 발주 필요일 C. 입고가 소진보다 늦으면 ⚠ 경고가 나옵니다.

  4. + 등록 을 누릅니다.

    이제 이 자재는 📦 발주 완료 로 표시되고, 상세 맨 위에 입고 대기 띠가 생깁니다.

따라하기 · 입고 확인 (실제로 들어왔을 때)
  1. 예정 줄(또는 맨 위 띠)의 ✓ 입고 확인 을 누릅니다.
  2. 실제 입고일 · 실제 수량 을 확인하거나 고칩니다.

    아래에 재고에 실제로 더해질 수량이 미리 보입니다. 입고일 앞 7일 안에 MES 매입이 있으면 ⚠ 입고일 앞 7일 안에 MES 매입이 있습니다 가 뜹니다. 그 MES 가 이번 입고와 다른 입고면 다른 입고(확인 수량을 모두 더함), 같은 입고면 같은 입고(MES 로 이미 들어온 몫은 빼고 더함)를 고릅니다.

  3. 재고에 반영 을 누릅니다.

    예정 없이 바로 넣으려면 종류 ✅ 입고 확인 → 날짜(오늘까지) · 수량 → + 입고 반영.

따라하기 · 보유수량 맞추기 (실제로 세어 봤을 때)
  1. 종류 🔢 보유수량 맞추기 를 고릅니다.
  2. 센 날짜 와 실제 보유 수량 을 넣습니다(0 도 됨).

    미리 보기에 계산과의 차이가 나옵니다.

  3. + 보유수량 맞추기 를 누릅니다.

    그날부터 이 수량에서 다시 셉니다.

  • 기록 고치기 : 수정 → 아래 칸에서 고침 → 저장. 지우기 : 삭제 → 확인. 입고 확인을 다시 예정으로 돌리려면 예정으로.
  • 저장은 화면에 바로 반영되고 서버 저장은 뒤에서 이어집니다. 실패하면 저장하지 못해 되돌렸습니다 가 뜹니다.

MES 입고와 저절로 맞춥니다

MES 매입(설정 › 업로드)이 실제 입고의 기준입니다. 같은 입고를 두 번 세지 않도록 화면 기록과 저절로 맞춥니다.

표시뜻
MES N 들어옴 · 남은 M예정 중 N 은 MES 로 들어왔고, 남은 M 만 앞날 계산에 씀
MES 반영 ✓입고 확인한 수량이 MES 에도 있음 (한 번만 셈)
MES 대기아직 MES 에 없음 — MES 가 올라오면 저절로 맞춤
🔗 MES 로 자동 확인 N건MES 로 다 들어온 예정 목록 (펼쳐서 확인)
앞 MES 와 다른 입고입고 확인 때 다른 입고 를 고른 기록 — 입고일 앞 7일 MES 와 따로 더함

협력사 발송 기록 (출발 예정 · 발송 확인)

협력사가 알려 준 출발 예정일과 실제로 보낸 날(발송 확인)을 입고 예정마다 적어, 물건이 오는 중인지 한눈에 봅니다. 입고 예정일 · 재고 계산은 바뀌지 않습니다.

따라하기 · 발송 기록 적기
  1. 상세 📦 입고 · 재고 기록 의 입고 예정 줄에서 🚚 발송 기록 을 누릅니다.

    줄 아래에 🚚 협력사 발송 칸이 열립니다. 이미 적었으면 단추 자리에 지금 상태(예: 🗓 11/20 출발 예정)가 보이고, 눌러서 고칩니다.

  2. 협력사가 알려 준 출발 예정일 을 넣고 저장 을 누릅니다.

    상태가 🗓 MM/DD 출발 예정 이 됩니다.

  3. 실제로 출발하면 실제 출발일 · 운송장 · B/L(선택)을 넣고 저장.

    오늘 출발했으면 🚚 오늘 발송 확인 한 번이면 됩니다. 상태가 🚚 MM/DD 발송 이 됩니다. 잘못 적었으면 기록 지우기.

표시뜻 · 할 일
🗓 MM/DD 출발 예정협력사가 알려 준 출발일 · 아직 발송 확인 전
🚚 MM/DD 발송실제로 출발함 (발송 확인) · 마우스를 올리면 운송장 · 출발 뒤 입고까지 며칠인지
⚠ 출발 MM/DD 지남출발 예정일이 지났는데 발송 확인이 없음 — 협력사에 실제로 보냈는지 확인

입고 지연 정리 · 품번 변경

따라하기 · 지연된 입고 예정 정리
  1. 목록 머리의 ⚠ 입고 지연 N · 정리 를 누릅니다.

    자재 · 예정일 · 수량 · MES 입고 · 메모가 나옵니다. MES 입고가 80% 이상이면 들어온 것 같습니다 가 붙습니다.

  2. 처리할 줄을 고릅니다.

    모두 고르기 또는 MES 입고가 확인된 N건 고르기.

  3. 알맞은 단추를 누릅니다.
    • ✓ 고른 N건 입고 확인 (재고 반영) : 실제로 들어왔는데 MES 에 없을 때
    • 고른 N건 MES 반영됨 : MES 에 이미 들어왔을 때
    • 고른 N건 삭제 · 날짜만 바꾸려면 줄의 날짜 수정
  • 🔁 품번 변경 규칙 : 공급업체가 바뀌어 완성품의 자재 품번이 바뀐 것을 적습니다. 적용일 · 완성품 · 새 품번 · 바꿀 품번(비우면 자동) · 메모 → + 줄 더하기 → 저장 · 다시 계산. 적용일부터 새 품번으로 사용량을 셉니다(예전 재고를 새 품번으로 옮기는 것은 아님).
  • 소진 후 사용 안 함 : 남은 재고만 쓰고 재주문하지 않는 자재로 바꾸는 상세 머리 스위치입니다. → 휴면 재고 · 소진 후 사용 안 함

발주계획관리 · 협력사에 SL 보내기

자재관리 › 발주계획관리

자재별 월 발주계획(SL)을 적고 협력사에 엑셀 · 메일로 보냅니다. FIRM = 이번 달 포함 4개월, FORECAST = 그 뒤 6개월입니다. 예) 11월이면 FIRM 11~2월, FORECAST 3~8월. 협력사에 보낼 때는 보낼 기간(최대 12개월)과 언어(한국어 / English)를 고릅니다.

따라하기 · 발주계획 적기
  1. 거르기로 자재를 좁힙니다.

    검색 · 조회 년월(그 달부터 10개월) · 품목군(기본 ★ 집중 관리) · 매입처 · 구분 · 고객사 · 계획 있는 자재만.

  2. ✎ 수정 을 누릅니다.
  3. 달 칸에 수량을 넣습니다.

    흐린 숫자는 그 달 예상 사용량, ≈ 는 계획 · S/L 이 끝난 달이라 마지막 3개월 평균으로 추정한 값입니다. Enter = 아래 칸, Tab = 옆 칸, Esc = 그 칸 되돌리기.

  4. 저장 (N) 을 누릅니다.

    바꾼 칸이 한꺼번에 저장됩니다. 그만두려면 취소(모두 되돌릴지 묻습니다). 쪽을 넘겨도 바꾼 칸은 남아 있습니다.

자동 채우기 · 범위 초기화 · 메모

  • ⚡ 자동 채우기 : 어느 자재(화면 전체 / 이 쪽 / 계획 있는 자재) · 어느 달(FIRM · FORECAST · 10개월) · 어느 칸(빈 칸만 / 덮어쓰기) · 3개월 평균 채우기 · VINFAST 백오더 반영(달별 %, 합 100%) → 채우기. 아직 저장되지 않았으니 저장 을 눌러야 합니다(↶ 되돌리기 가능).
  • 🧹 범위 초기화 : 자재 · 달을 골라 수량만 지웁니다(메모는 남음). 이것도 저장 해야 반영됩니다.
  • 📝 메모 : 자재 메모 · 달마다 메모 · 고친 기록. 주황 점이 있는 칸은 그 달 메모가 있다는 뜻입니다.

협력사에 보내기

따라하기 · SL 엑셀 · 메일
  1. 보낼 매입처로 거른 뒤 ⬇ SL 엑셀 (협력사 공유용) 을 누릅니다.

    SL 엑셀 · 메일 (협력사 공유용) 창이 뜹니다. 자재는 지금 거르기 그대로(모든 쪽)입니다.

  2. 보낼 기간 을 고릅니다.

    시작 월 ~ 끝 월(최대 12개월), 또는 당월부터 FIRM 4개월 · 6개월 · 10개월. 처음 값은 조회 년월부터 10개월입니다. → 보낼 기간 고르기

  3. 언어 를 확인합니다.

    해외 업체는 처음부터 English, 국내 업체는 한국어 가 골라져 있습니다. → 영문 SL 보내기

  4. 협력사에 전할 말 을 적습니다(비워도 됨).

    엑셀 위쪽과 메일 본문에 들어갑니다.

  5. 파일로 받으려면 ⬇ 엑셀 내려받기, 메일로 보내려면 봉투 아이콘(이메일로 보내기)을 누릅니다.
  6. ✉ SL 메일 보내기 창에서 받는 사람(필수) · 참조 · 제목 · 본문을 확인합니다.

    언어 · 보낼 기간은 이 창에서도 바꿀 수 있습니다(고친 제목 · 본문은 그대로 두고 기간 글자만 새 달로). 매입처를 골랐다면 '매입처' 주소록에 저장 을 체크해 다음에 다시 씁니다. 본문 자리표 : {매입처} {FIRM} {FORECAST} {기간} {전할말}.

  7. 첨부 ⬇ 미리 받기 로 엑셀을 열어 본 뒤 ✉ 보내기.

    창 아래 보낸 기록 에 때 · 누가 · 받는 사람 · 제목 · 기간(개월 · English) · 결과가 남습니다.

이 SL 메일은 직접 보낼 때만 나갑니다. 사내 조달 알림 메일(이메일 설정)과는 다른 기능입니다.

해외 업체에 영문 SL 보내기

따라하기 · 영문 SL
  1. 해외 업체로 거르고 ⬇ SL 엑셀 (협력사 공유용) 을 누릅니다.

    그 매입처 자재의 절반 이상이 해외(수입)면 해외 업체 — 영문 자동 (AI 번역) 으로 English 가 먼저 골라집니다. 국내 업체도 English 를 누르면 영문으로 보낼 수 있습니다.

  2. 전할 말은 한글로 적어도 됩니다.

    English 면 제목 · 본문 · 엑셀(시트 이름 Schedule Line · 머리글 Part No. · Description …)이 영어가 되고, 한글 전할 말 · 품명 · 메모는 AI 가 영어로 옮깁니다.

  3. 메일 창에서 제목 · 본문을 읽어 봅니다.

    ⚠ 제목 · 본문에 한글이 남아 있습니다 가 뜨면 🌐 AI 영문 번역 을 누르거나 영어로 고칩니다.

  4. ⬇ 미리 받기 로 영문 엑셀을 확인하고 ✉ 보내기.

    보낸 뒤 엑셀에 번역 못 한 한글 N건 이 뜨면 엑셀 안에 한글이 남은 것이니 품명 · 메모를 확인하세요.

  • 기본 문구는 한국어 · 영문 따로 저장됩니다(💾 기본 문구로 저장 · ↺ 처음 문구). 영문 자리표 : {SUPPLIER} {PERIOD} {MONTHS} {FIRM} {FORECAST} {NOTE}.
AI 번역은 틀릴 수 있습니다. 품번 · 수량 · 날짜는 그대로 두지만, 보내기 전에 꼭 한 번 읽어 주세요.

무상출고요청 (샘플 · 반출)

자재관리 › 무상출고요청보기 · 요청 : 자재관리 권한 · 확인 · 출고 : 생산관리팀 · 마스터 · 엑셀 올리기 : 마스터

샘플 · 반출처럼 돈을 받지 않고 내보내는 자재 · 제품을 요청하고, 생산관리팀(생관팀)이 확인 · 출고까지 처리하는 곳입니다. 매달 쓰던 「샘플 & 반출 의뢰서」 엑셀을 대신하고, 처리 결과는 자재관리 재고 · 입고 예정에 그대로 이어집니다.

  • ① 요청요청자 · + 새 요청 (품번 · 수량 · 목적 · 필요일자)
  • ② 확인생관팀 · 처리 방식 · 공급 가능일 · 예상입고일 → 자재관리 입고 예정
  • ③ 출고 완료생관팀 · 출고수량 · 일자 · 장소 → 자재관리 재고에서 뺌
화면 구성 · 위에서 아래로
  1. 숫자 카드 4장확인 기다림 · 처리 중 · ⚠ 지연(필요일자가 지났는데 출고 전) · 출고 완료 — 누르면 그 요청만 보입니다
  2. 머리무상출고 요청 · 기간 · 건수 · 상태 막대 · 내 권한 표시 · + 새 요청 · 📤 엑셀 올리기(마스터)
  3. 생관팀 담당수입자재 · 국내자재 · 완제품별 담당자 이름 (엑셀 맨 위 줄에서 읽음)
  4. 거르기검색 · 기간 (의뢰서 달) 연도 · 월 ‹ › · 상태 · 구분 · 자재/제품 · 출고유형 · 의뢰자 · 내 담당 · 내 요청만 · ↺ 초기화
  5. 표No · 품번 · 품명 · 구분 · 요청수량 · 필요일자 · 출고유형 · 공급 가능 · 입고 예정 (자재관리) · 출고 · 자재관리 재고 · 담당 · 상태 · 할 일 — 같은 의뢰(의뢰자 · 목적 · 필요일자)는 한 묶음

처음에는 이번 달 요청이 보입니다. ‹ › 로 달을 옮기고, 이번 달 로 돌아옵니다. 위 메뉴 무상출고요청 옆 숫자는 생관팀에게는 확인 기다림 + 늦은 처리 중 건수, 그 밖의 사람에게는 지연 건수입니다.

상태뜻 · 지금 차례
대기요청만 들어옴 — 생관팀 확인 차례 (요청자는 아직 고치거나 지울 수 있음)
확인 · 처리 중생관팀이 처리 방식 · 날짜를 정함 — 출고 차례
출고 완료내보냄 — 자재관리 재고에서 뺌
반려처리하지 않음 — 반려 이유가 기록에 남음
⚠ 지연샘플 필요일자가 지났는데 아직 출고 전

요청하기 (요청자)

따라하기 · 새 무상출고 요청
  1. + 새 요청 을 누릅니다.

    + 새 무상출고 요청 창이 열립니다. 한 의뢰에 품번 여러 줄을 함께 넣습니다.

  2. 위 칸에 의뢰자 · 구분 · 차종 · 샘플 필요일자 · 목적 을 넣습니다.

    예) 목적 : KGM 개발 검증 샘플 · JG 리워크용 부품

  3. 줄마다 자재/제품 을 고르고 품번 을 넣습니다.

    품번만 넣으면 품명 · 단위가 저절로 들어가고 잠깁니다(✓ 일치). 없는 품번이면 ✗ 품목정보에 없는 품번 과 비슷한 품번이 나오니 골라 주세요.

  4. 요청수량 을 넣고, 필요하면 출고유형 (희망) · 비고 를 적습니다.

    출고유형은 비워 두면 생관팀이 정합니다(창고재고 · 생산요청 · 입고요청). 줄이 더 필요하면 + 줄 더하기, 빼려면 줄 끝 ✕.

  5. 요청 등록 을 누릅니다.

    요청 N줄을 등록했습니다 — 생관팀 확인을 기다립니다. 가 뜨고 상태는 대기 입니다. 어디에도 없는 품번이면 그대로 등록 / 품번 고치기 를 묻습니다.

  • 내가 화면에서 쓴 대기 요청은 줄의 수정 · 지우기 로 고치거나 지울 수 있습니다. 생관팀이 확인한 뒤에는 생관팀만 고칩니다.
  • 줄을 누르면 오른쪽에 상세 창이 열립니다 : ① 요청 → ② 확인 → ③ 출고 완료 진행, 요청 내용, 생관팀 처리, 같은 품번의 자재관리 재고 · 소진 예상, 처리 기록(누가 · 언제).
  • 내 것만 보려면 내 담당 · 내 요청만 을 체크합니다.

확인 · 출고 처리 (생관팀)

계정 부서에 '생산관리' 또는 '생관'이 들어 있는 사람과 마스터만 할 수 있습니다. 머리에 ✓ 생관팀 처리 권한 이 보이면 됩니다.

따라하기 · 확인 처리
  1. 대기 줄의 ✓ 확인 을 누릅니다.

    여러 줄은 왼쪽 칸을 체크하고 위 띠의 ✓ 확인 으로 한 번에 합니다. 묶음 머리를 체크하면 그 의뢰 전체가 골라집니다.

  2. 처리 방식 을 고릅니다 : 창고재고 · 생산요청 · 입고요청.
  3. 공급 가능일자 와, 들어올 자재면 예상입고일 을 넣습니다.

    여러 줄이면 (모두에 넣기) 로 같은 날짜를 채웁니다. 필요하면 메모.

  4. 줄마다 입고 예정 수량 과 자재관리 입고 예정 의 올리기 를 확인합니다.

    올리기를 켜면 자재관리 같은 품번의 입고 예정(🎁 표시)에 그대로 올라갑니다. 입고요청이면 처음부터 켜져 있습니다. 자재관리 목록에 없는 품번(완성품 등)은 목록에 없음.

  5. ✓ 확인 처리 를 누릅니다.

    상태가 확인 · 처리 중 으로 바뀝니다. 날짜를 바꾸려면 줄의 수정.

따라하기 · 출고 완료
  1. 처리 중 줄의 📦 출고 를 누릅니다.

    대기 줄을 바로 내보낼 때는 상세 창의 📦 바로 출고 완료, 여러 줄은 체크 뒤 위 띠의 📦 출고 완료.

  2. 출고일자(오늘까지) · 출고장소(창고 · 라인)를 넣습니다.
  3. 줄마다 출고수량 과 재고에서 빼기 를 확인합니다.

    켜 두면 출고일자에 출고수량만큼 자재관리 입고 · 재고 기록에 − 로 들어가 재고 · 소진 예상이 바로 바뀝니다. 수량이 「1 BOX」 처럼 글자면 기록만 남고 재고에서는 빼지 않습니다(숫자로 넣으면 뺌).

  4. 📦 출고 완료 를 누릅니다.

    상태가 출고 완료 가 되고 표의 출고 칸에 재고 −N 이 보입니다.

  • 반려 : 반려 → 반려 이유(필수) → 반려. 다시 받으려면 상세 창의 반려 풀기.
  • 되돌리기(상세 창) : 확인 취소 = 대기로 (자동으로 올린 입고 예정은 지움 · 이미 입고 확인된 것은 그대로) · 출고 완료 취소 = 처리 중으로 (재고에서 뺀 기록을 지워 재고를 다시 더함).
상세 창의 지우기 는 이어진 자재관리 입고 예정 · 재고 기록까지 함께 지우며 되돌릴 수 없습니다.

의뢰서 엑셀 올리기 (마스터)

따라하기 · 「샘플 & 반출 의뢰서」 올리기
  1. 📤 엑셀 올리기 를 누르고 파일을 끌어 놓습니다.

    여러 파일을 한 번에 골라도 됩니다. 파일 이름의 달(예: 2026 10월 무상출고.xlsx → 10월)을 의뢰서 달로 씁니다.

  2. 파일마다 미리 보기를 확인합니다.

    새 요청 · 바뀜 · 같음 건수와 경고(날짜를 못 읽은 칸 등)가 나옵니다. ▸ 줄 보기 로 줄을 펼쳐 봅니다.

  3. 저장 을 누릅니다.

    다시 올리면 같은 줄(달 · No · 품번)은 고치고 새 줄만 더합니다. 화면에서 생관팀이 처리한 값은 덮지 않습니다. 출고 완료된 줄은 출고 완료된 줄은 자재관리 재고에서 빼기 로 재고에도 반영할 수 있습니다.

같은 파일의 「품목정보」 시트도 저장되어, + 새 요청 창에서 품번만 넣으면 엑셀 VLOOKUP 과 같은 품명 · 단위가 들어갑니다.

  1. 상태 막대에서 생산불가 또는 긴급 을 누릅니다.

    앞으로 계획이 있는 것만 은 처음부터 켜져 있습니다. 검색(완성품 · 라인 · 자재 품번) · 라인 · 상태 로도 좁힙니다.

  2. 표를 봅니다.

    자재 충족(막대 + 부족 N) · 병목 자재 · 단독 생산 가능 · 부족 시작일 · 앞으로 계획 · 막히는 계획 수량. ▶ 를 누르면 자재 줄이 펼쳐집니다.

  3. 줄을 누르면 완성품 상세가 열립니다.

    그래프(진청록 실적 · 연청록 생산계획 · 연보라 VINFAST 롤링 S/L · 빨강 막히는 계획), 날짜별 생산계획(생산 가능 / 일부만 가능 / 생산 불가), 연결 자재 (BOM).

  4. 병목 자재 줄을 눌러 자재 정보를 보고, 자재관리에서 입고 · 발주를 챙깁니다.

    돌아가려면 ← 목록으로 돌아가기.

자세한 판정 기준은 화면 아래 생산 차질 점검 보는 법 을 펼쳐 보세요.

수불부 기준

8월 말 수불부(기준 재고)를 품번별로 봅니다. 검색(품번 · 품명 · 업체)과 시트 로 좁히고, 제목 줄에서 품번 수 · 기말 수량 · 기말 금액을 봅니다. 표 : 품목코드 · 품목명 · 업체 · 시트 · 기초 · 입고 · 출고 · 기말 · 기말 금액 · 구분. 줄을 누르면 자재 옆 창이 열립니다.

따라하기 · 자동 메일 설정
  1. 맨 위 자동 발송 스위치를 켭니다.
  2. ① 에서 묶음마다 예약 스위치 · 시각 · 매일 또는 요일 선택 을 정합니다.

    ◉ 는 미리보기 · 시험 · 지금 보내기 대상 묶음입니다. 같은 묶음은 하루 한 번만 나가고, 보낼 것이 없으면 건너뜀 으로 기록됩니다.

  3. ② 넣을 표를 고릅니다.

    즉시 조달 · 이번 주 발주 · 4주 안 발주. 해외 + 국내 고르기는 전체 묶음에만 쓰입니다.

  4. ③ 받는 사람을 펼쳐 확인합니다.

    세 묶음이 같은 사람에게 갑니다. 이름 · 아이디 · 주소 일부로 찾아 Enter, ⇄ 또는 끌어서 받는 사람 ↔ 참조, × 로 뺍니다.

  5. 미리보기 → 나에게 시험 메일 로 확인하고 저장.

    바로 보내려면 지금 보내기(◉ 묶음 · 그 묶음의 오늘 자동 발송은 건너뜀).
