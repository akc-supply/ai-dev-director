자주 묻는 질문

막혔을 때 먼저 여기를 보세요. 제목을 누르면 답이 펼쳐집니다.

로그인 · 화면

메뉴가 보이지 않습니다

그 화면 권한이 없는 것입니다. 고장이 아닙니다. 관리자(마스터)에게 필요한 화면을 요청하세요. → 등급과 권한

비밀번호를 잊었습니다

로그인 화면의 비밀번호를 잊으셨나요? 에서 아이디 · 이름 · 사번을 넣으면 임시 비밀번호(30분)가 뜹니다. → 비밀번호 찾기

인증번호 메일이 오지 않습니다

스팸함을 확인하고 1분 뒤 인증번호 다시 보내기 를 누르세요. 계정에 적힌 메일 주소가 틀렸다면 관리자에게 고쳐 달라고 요청하세요.

쓰던 중에 로그아웃되었습니다

30분 동안 아무것도 하지 않으면 자동으로 로그아웃됩니다. 2분 전 창에서 계속 사용 을 누르면 이어집니다. 설치한 안드로이드 앱과 VF 출하관리 화면(08~19시)은 예외입니다.

숫자가 예전 그대로입니다 · 다른 사람이 올린 자료가 안 보입니다

자료는 저절로 반영되지만, 입력 칸에 글을 쓰는 중이면 다 쓴 뒤에 바뀝니다. 그래도 그대로면 F5(새로고침)를 누르세요. 자재관리는 새로 계산 을 누릅니다.

내려받은 엑셀이 형식 경고를 냅니다

예 를 누르면 정상으로 열립니다. 다른 이름으로 저장하면 일반 엑셀 파일이 됩니다.

재고 · 출하

재고가 실제보다 적게 나옵니다

출고가능 재고에는 아직 나가지 않은 대기 인보이스 수량이 빠져 있습니다. 이미 나간 것이라면 VF 출하관리에서 출하하기 를 눌러 주세요. 차감이 풀립니다.

이번 달 목표(S/L)가 바뀌지 않습니다

정상입니다. 이번 달 목표는 지난 달 마지막 S/L 회차로 정해져 달 중간에 흔들리지 않습니다. 백오더는 최신 회차를 씁니다.

같은 인보이스를 다시 올릴 수 없습니다

파일 이름에 _Rev01 처럼 더 높은 Rev 번호를 붙여 주세요. 같거나 낮은 Rev 는 들어가지 않습니다. → 인보이스 올리기

출하관리에 인보이스가 보이지 않습니다

INV 발행에서 저장했는지, 또는 출고가능 재고에 엑셀을 올렸는지 확인하세요. 보기 가 대기 인지, 지역 · 운송 · 검색 조건이 걸려 있지 않은지도 보세요.

알림 소리가 나지 않습니다

브라우저는 화면을 한 번도 누르지 않으면 소리를 막습니다. 화면을 한 번 누르고 🔊 소리 시험 을 눌러 보세요. 🔕 알림 꺼짐 이면 눌러서 켭니다. → 알림

업로드를 잘못했습니다

출하데이터 · 생산실적은 해당 월만 교체를 켠 채 그 달 파일만 다시 올리면 됩니다. 주간 S/L 은 같은 날짜로 다시 올려 덮어쓰기 하거나 S/L 스냅샷 삭제 로 지웁니다.

금액이 0 으로 나오는 품번이 있습니다

단가가 등록되지 않은 품번입니다. 노란 띠의 품번을 업로드 › 단가 관리 에 넣어 주세요.

자재 · 메일 · 기타

무상출고요청에 확인 · 출고 단추가 보이지 않습니다

확인 · 출고 · 반려는 계정 부서에 '생산관리'(또는 '생관')가 있는 사람과 마스터만 할 수 있습니다. 다른 사람은 요청 · 보기만 됩니다. 엑셀 올리기는 마스터만 됩니다. → 확인 · 출고 처리

쓰는 자재인데 휴면으로 나옵니다 (또는 그 반대)

자재 상세 머리의 💤 휴면 재고 스위치로 직접 바꿉니다. 끄면 다시 결품 · 발주 알림 대상이 됩니다. → 휴면 재고 · 소진 후 사용 안 함

영문 SL 메일에 한글이 남아 있습니다

메일 창의 🌐 AI 영문 번역 을 누르거나 직접 영어로 고치세요. AI 번역이 안 되면 한글이 그대로 남으니 보내기 전에 읽어 주세요. → 영문 SL 보내기

입고 예정이 있는데 왜 '입고 확인 필요'인가요?

예정은 실제 입고가 아닙니다. 예정이 들어와야만 정상이거나 예정일이 지났다면, 실물이 들어왔는지 확인하고 ✓ 입고 확인 을 눌러 주세요. MES 에 이미 들어왔다면 MES 반영됨 으로 정리합니다.

메일 결과가 분명하지 않을 때 바로 다시 보내도 되나요?

먼저 보낸 기록에서 상태 · 받는 사람 · 시각을 확인하세요. 일부 못 받음 이면 거절된 주소만 확인하면 됩니다. 기록과 반송 메일을 본 뒤 다시 보낼지 정하세요.
